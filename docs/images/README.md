# Capturas da interface

As imagens desta pasta documentam a interface do EEG Brain 3D. As capturas mantêm os rótulos dos participantes fornecidos pelos datasets; não representam exemplos anonimizados.

## Organização

- `shot-*.png`: imagens de referência usadas na documentação técnica e no README.
- `hbn/`: visualização de registros HBN.
- `med/`: sequência de exploração de sinais, filtros e fontes.
- `wizard/`: etapas do assistente de importação.

Os nomes originais foram preservados para manter a sequência das capturas. Os arquivos desta pasta são documentação; os recursos usados pela aplicação ficam em `assets/` na raiz.
